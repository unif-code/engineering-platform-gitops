# 160-business-ready-evidence

Writes metadata-only mode-600 evidence and a SHA-256 sidecar for the current Git commit.
Secret values and one-time account credentials are never captured.

## 停止原因

- `admin-conf-content-or-structure-drift`
- `applications-not-ready`
- `base64-provenance-drift`
- `curl-provenance-drift`
- `evidence-open-failed`
- `git-commit-unreadable`
- `https-smoke-failed`
- `kubectl-provenance-drift`
- `not-root`
- `openssl-provenance-drift`
- `secret-metadata-query-failed`
- `untrusted-environment-override`
